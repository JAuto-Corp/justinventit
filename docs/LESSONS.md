# Lessons from the JA extraction

This catalogue graduates reusable engineering and agentic lessons from the JA memory corpus. Use the relevant topic when investigating or designing a change; it is reference material, not an additional boot checklist. Each entry preserves a practical check, the failures that motivated it, and a representative dated historical origin; the evidence ledger maps all supporting notes.

Existing policy remains in [Architecture](ARCHITECTURE.md), [Context Contract](CONTEXT_CONTRACT.md), [Development Loop](DEV_LOOP.md), [Review Practice](REVIEW_PRACTICE.md), [TDD Gate](TDD_GATE.md), [Seat Protocol](SEAT_PROTOCOL.md), [Delivery](../template/docs/DELIVERY.md) and [Skill Modes](../template/docs/SKILL_MODES.md). Linked policy owns authority, gates and exceptions; this catalogue explains the experience behind it. A lesson does not confer permission to send, merge, change a shared environment, launch a reviewer or clean up another worker’s resources.

Dates, JA issue/PR numbers and memory filenames below are **historical provenance only**. Runtime, SDK and provider observations are version- and environment-specific evidence: reproduce the mechanism in the current target before adopting a remedy. Corrections supersede the original diagnosis. This extraction adds documentation, not the future machinery or isolation adapters. Source memory remains unchanged.
